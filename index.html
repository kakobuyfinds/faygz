How to use a CSSBuy spreadsheet

Use the catalog to build a shortlist. Keep the original seller link, variant and measurements together so you can check the same item at each step.

Find the original seller link

Open the HipobuyFind listing and look for the original marketplace link. Paste that seller link into CSSBuy and verify that the item, color and size match before ordering.

Review warehouse QC photos

Compare the photos with the selected variant. Look for visible damage, check labels and request a photo with a measuring tape if fit depends on a specific dimension. Check the return window before approving shipment.

Estimate the delivered cost

Add item cost, domestic delivery, any agent fees and international shipping. Compare quotes using the packed dimensions and weight, since some shipping lines bill by volumetric weight.

Illustrative budget. A $25 item, $3 domestic delivery, $2 in fees and $18 international shipping come to $48 before any applicable taxes or duties. Use your actual parcel quote when budgeting.

Frequently asked questions

What is a CSSBuy spreadsheet?

It is a product discovery list that helps shoppers organize potential purchases before ordering through a shopping agent. This page combines selected HipobuyFind listings with instructions for checking the original seller link and item details.

Where does Buy it now take me?

It opens HipobuyFind. Use the individual catalog links above to see a specific listing and look for the original seller link.

Why can the price change after I select a size or color?

Seller listings can price variants differently. Currency conversion and agent charges can also affect the amount you pay. Check the selected variant and order summary before submitting payment.

What should I do if a product link stops working?

Search HipobuyFind using the product name or browse the matching category. Confirm the seller, size chart and specifications before ordering a replacement listing.
